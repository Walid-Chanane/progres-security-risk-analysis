# PROGRES Security Risk Analysis

This project was developed as part of a **Cybersecurity** module and focuses on the security analysis and planning of the **PROGRES platform**.

## Overview

The project addresses the security and continuity of the PROGRES platform through three main areas:

- **EBIOS-RM Risk Analysis**
- **Information Security Policy**
- **Business Continuity Plan**

### EBIOS-RM Risk Analysis

The risk analysis covers:

- Study scope and security baseline
- Essential and supporting assets
- Risk sources
- Strategic scenarios
- Operational scenarios
- Risk treatment

### Information Security Policy

The project defines an information security policy covering:

- Strategic elements and recommendations
- Strategic security objectives
- Security rules

### Business Continuity Plan

The Business Continuity Plan addresses several security and continuity procedures, including:

- Data backup and restoration
- Continuous activity monitoring
- Sensitive data encryption
- Access control
- Antivirus management
- Security audits
- Security training and awareness
- Firewall management
- Backup servers and automatic failover
- Incident management
